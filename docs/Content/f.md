# Week 6

System administration work requires a basic competence at the Linux command prompt. Go through the simple exercises I provide [here](https://jor-donegal.github.io/LinuxCLI26/).

But automation requires us to be able to write scripts. My [follow on notes](https://jor-donegal.github.io/LinuxScripts26/) go into some aspects of Linux a little more and introduce you to scripting.

Create a folder called Linux in your repo and when complete, upload a brief report in a PDF format. Each script should be included in an appendix, along with a screen shot of it running. I will talk through how to approach this report, do not submit it until I have done so.
